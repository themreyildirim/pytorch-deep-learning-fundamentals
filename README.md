# PyTorch Deep Learning \& Computer Vision Labs

End-to-end deep learning and computer vision implementations with PyTorch: from basic tensor workflows to modular CNN benchmarks and transfer learning pipelines.

## 📌 Projects \& Modules

1. **01. PyTorch Workflow \& Linear Modeling:** Core   
n.Module\\ architecture, device-agnostic setup (GPU/CPU), training loops, and model saving/loading (\\state\_dict).
2. **02. FashionMNIST Multi-Class Benchmark and Custom Dataset:** Comparative analysis between Linear, Non-linear (ReLU), and Convolutional (TinyVGG Conv2d/MaxPool2d) architectures with confusion matrix evaluations.
3. **03. Fine-Grained Dog Classification (Transfer Learning):** High-accuracy vision pipeline leveraging \\	orchvision.transforms.v2\\ and pretrained \\EfficientNet-B0\\ backbone (achieving 90%+ test accuracy).
4. **04. Large-Scale Bird Classification Pipeline:** KaggleHub dataset integration, custom \\DataLoader\\ optimizations, and visualization grids for multi-class classification.

## 🛠️ Tech Stack

* PyTorch, Torchvision
* Matplotlib, NumPy, Pandas
* Torchinfo, Torchmetrics, MLxtend
